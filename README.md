# My First Project

A simple Java program that calculates the next time by adding a specified number of minutes to a given time.

## 📖 Description

This project was created as a beginner Java practice project and to learn how to use GitHub. The program takes an input time (hour and minute), adds a given number of minutes, and displays the resulting time in **HH:MM** format.

## ✨ Features

* Calculate time by adding minutes
* Automatically handle hour overflow
* Automatically wrap around after 24 hours
* Display output in `HH:MM` format

## 🛠️ Built With

* Java
* `java.util.Scanner`

## ▶️ How to Run

1. Compile the program:

```bash
javac main.java
```

2. Run the program:

```bash
java main
```

## 💻 Usage

Enter three integers in the terminal:

* Hour (0–23)
* Minute (0–59)
* Minutes to add

### Example

**Input**

```text
10
20
80
```

**Output**

```text
11:40
```
